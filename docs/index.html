Aplicativo Web para Consulta das Academias de Londrina/PR

Projeto de extensão universitária desenvolvido ao longo das disciplinas EGS@1019 a EGS@1037 do curso de Engenharia de Software (EaD, UniFil). O aplicativo permite consultar academias de Londrina com filtros por bairro, modalidade e termo livre — sem cadastro, sem login e 100% offline-first.

Arquitetura e tecnologias

A aplicação é construída com Next.js 15 (App Router) + React 19 em TypeScript. A UI usa Tailwind CSS. O modelo de dados é mantido em Prisma + SQLite em desenvolvimento; em produção, os dados são exportados para JSON estático, o que permite deploy em qualquer ambiente serverless sem depender de filesystem gravável.

Qualidade e testes

Vitest — testes unitários

10 / 10

Cobrem filtros, ordenação, busca por id e listagens auxiliares do repositório.

Playwright — e2e

6 / 6

Validam home, filtros, detalhes, 404 e Sobre no navegador Chromium.

Os refinamentos aplicados na Extensão VII incluem: busca tolerante a acentos (normalização Unicode NFD), aria-label em todos os campos de filtro, estados focus-visible acessíveis e aria-live para o contador de resultados.

Como executar localmente

git clone https://github.com/higorseixas/academias-londrina
cd academias-londrina
npm install
npx prisma migrate deploy   # cria o SQLite a partir das migrations
npx prisma db seed          # popula com 15 academias
npm run db:export           # gera src/data/academias.json
npm run dev                 # http://localhost:3000

Comandos úteis

  • npm test — roda os 10 testes Vitest
  • npm run test:e2e — roda os 6 testes Playwright
  • npm run build — build de produção
