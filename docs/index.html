Aplicativo Web para Consulta
das Academias de Londrina/PR

Uma solução simples, offline-first e sem cadastro para conectar moradores de Londrina às academias da cidade por bairro, modalidade ou nome. Resultado de oito extensões curriculares do curso de Engenharia de Software.

❓ Problema

Encontrar academia em Londrina não era simples

Londrina tem centenas de academias espalhadas por seus bairros. Até hoje, quem muda de endereço, chega de outra cidade ou simplesmente quer trocar de academia precisa combinar várias fontes dispersas: busca no Google, Instagram de cada academia, perguntas em grupos de bairro, Google Maps. O resultado é um processo demorado, enviesado por propaganda e que exclui academias menores que não investem em marketing digital.

Esse é um problema real, não hipotético: moradores perdem tempo, academias pequenas perdem clientes potenciais, e a informação disponível é inconsistente — preço desatualizado, modalidade inexistente, telefone antigo.

PAIN POINTS LEVANTADOS

  • ⚠️ Informações pulverizadas entre Instagram, Google e Maps
  • ⚠️ Viés de busca favorece academias com mais marketing
  • ⚠️ Impossível filtrar por "modalidade + bairro" num único lugar
  • ⚠️ Dependência de login em redes sociais
  • ⚠️ Dados desatualizados sem fonte única de verdade
✓ Solução

Um catálogo público, filtrável e sem cadastro

O Aplicativo Web consolida as academias de Londrina em um único catálogo navegável, com três filtros combináveis — bairro, modalidade e termo livre. Toda consulta é feita em menos de dois segundos, sem cadastro, sem login, e sem dependência de servidores externos.

Arquitetura e tecnologias

A aplicação é construída com Next.js 15 (App Router) + React 19 em TypeScript, estilizada com Tailwind CSS. A camada de dados usa Prisma + SQLite em desenvolvimento e JSON estático em produção — escolha arquitetural que viabiliza deploy em qualquer ambiente serverless (Vercel, Netlify, Cloudflare) sem depender de filesystem gravável.

Frontend

Next.js 15 · React 19

  • App Router com Server Components
  • TypeScript strict mode
  • Tailwind CSS utility-first

Dados

Prisma · SQLite · JSON

  • Prisma espelha o DER
  • Seed com 15 academias reais
  • Export JSON para serverless

Qualidade e Deploy

Vitest · Playwright · Vercel

  • 16 testes automatizados
  • Build de produção zero warnings
  • Deploy contínuo via CLI

🌍 Impacto para a sociedade

Para quem esse projeto importa

🏠

Moradores novos em Londrina

Pessoas que acabaram de mudar para a cidade conseguem, em segundos, encontrar academias próximas do seu bairro novo sem precisar pedir indicação nem acessar múltiplas redes sociais.

🏃

Praticantes de modalidades específicas

Quem procura Pilates, CrossFit ou Jiu-Jitsu numa região específica filtra pelos dois critérios de uma vez, sem depender de anúncios patrocinados ou buscas aleatórias.

💼

Academias de bairro

Pequenas academias ganham visibilidade equivalente às grandes, já que o catálogo é curado e neutro — não há posicionamento pago, cada academia aparece pelo mérito do seu nome e dos seus serviços.

"O projeto demonstra que um software socialmente relevante não precisa ser complexo. Com uma arquitetura simples, 15 academias cadastradas e três filtros combináveis, o aplicativo resolve um problema cotidiano real da comunidade londrinense, respeitando privacidade (sem cadastro) e inclusão (acessível)."

— Reflexão do autor na Extensão VIII
